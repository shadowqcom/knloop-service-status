## 仓库分支规范
开发和修复bug时请在dev分支上进行，修复完成后请合并到page和main分支。

## 修改代码和新增模块的过程中请严格遵守本项目技术栈:
- Alpine.js
- Tailwind CSS 4
- SVG sprite

必要时联网查看以上技术栈最新文档接口，在接下来的修复错误和开发新组件的过程中请使用所属技术栈的最新api，严格遵守官方推荐的开发规范。

## 开发环境
- 当前使用的是windows系统，命令行是powershell。

## 禁止事项:
- 任务完成后不需要运行npm run dev命令。
- 禁止一次在命令行中运行多个命令。

## 打包测试必须做到:
- 0 errors
- 0 warnings
- 0 hints
